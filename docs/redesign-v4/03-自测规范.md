# 胥宇改版 v4 · 自测规范

目标：**用户实际用到的和规格写的一致**，并且每个模块之间的衔接都被测到。自测报告靠证据说话，不靠“我觉得没问题”。

本规范接入现有命令和流程，不另起一套（协调仓 AGENTS 第 20、21 条）：

| 用途 | 现有命令 |
|---|---|
| 类型检查 / Lint | `npm run typecheck`、`npm run lint` |
| 单元 / 集成 | `npm run test:unit`、`npm run test:integration`（vitest） |
| 端到端 | `npm run test:e2e`（Playwright + Electron） |
| UI 回归 | `node ../project-coordination/scripts/project-handoff.mjs ui-audit`、`ui-audit --verify` |
| 元数据 | `npm run metadata:check` |

所有自动测试都在**后台、隔离数据目录**里跑，不开可见窗口、不抢前台（第 5、22 条）。

## 5. 跨模块旅程（G3）

每条旅程从用户真实的起点开始，走到真实的终点，中间跨越模块时**断言数据真的传过去了**（而不只是界面切换了）。全部用夹具和隔离数据目录，不碰用户数据。

选择器约定：所有被测控件带 `data-testid`，命名 `模块.区域.控件`，例如 `editor.toolbar.export`、`summary.list.row`、`summary.list.primary`、`titlebar.theme`、`workbench.new.row`。每个可点击操作另带 `data-command-id`（G-07）。

## 6. 窗口尺寸矩阵（G4）

尺寸：900×500（最小）、960×1040（1080p 屏半屏）、1280×720、1366×768、1536×864、1920×1080、2560×1440、3440×1440（带鱼屏）、5120×1440。

每个尺寸、在“绘图页已打开图纸、所有浮窗展开”状态下断言：

1. 任意两个浮窗的包围盒不相交（允许 0 像素接触）。
2. 工具栏只有一行：高度 ≤ 48px，且所有按钮的 `top` 相同。
3. 标题栏交互控件不进入系统按钮区域。
4. 宽 < 1180 时同时展开的浮窗列数 ≤ 1。
5. “居中撑满”后，图纸可见区域不被浮窗遮挡（图纸包围盒与浮窗包围盒不相交）。

## 7. 动效断言（G5）

在打开图纸、切模块、换主题、改数量、放点位、放汇总、出错提示、批量导出这几个场景各触发一次，然后检查 `document.getAnimations()`（规格 M-02 三档）：

- **交互档**：非 `fx-` 开头、非无限循环的动画，`effect.getTiming().duration ≤ 320`；
- **余晖档**：`fx-` 开头的动画，单次 `duration ≤ 1200`，且目标元素 `pointer-events` 为 `none` 或动画期间不拦截点击（在动画进行中点击下面的控件，操作照常生效）；
- **持续档**：`iterations === Infinity` 的动画，对应状态结束后 500ms 内必须全部停止（例如导出完成后不再有转圈）；
- 所有动画的关键帧里不出现布局属性（`width / height / top / left / right / bottom / inset / margin* / padding* / font-size`）；
- 在“减少动效”模式下重复一遍：交互和余晖动画 1ms 内结束，持续档改为静态指示，功能结果与正常模式相同；
- M-04 落点表逐项抽查：每个落点触发一次，断言对应类名出现过或对应函数被调用过（在测试构建里给 `feedback` 工具加计数钩子）。

## 9. 用户验收清单（G7，约 15 分钟）

由用户在 Windows 上通过“胥宇 Preview.lnk”运行当前源码版本完成。每项打 ✓ 或写问题。

**每个阶段都看**
- [ ] 平时用的快捷键（包括自己绑的 1 / 2 / 3 / 4）都还在、还是原来的功能。
- [ ] 打开一份以前画过的图纸，图上内容没有任何变化。

**P1**
- [ ] 放几个点位，点一下画布空白处，再点设备汇总：图例从点的位置开始排，文字没有压在一起。
- [ ] 在属性里把录像机数量改成 2，再点一次设备汇总：还是 2，位置没动。
- [ ] 导出 PDF，和屏幕上看到的一样（换行位置也一样）。

**P2**
- [ ] 顶上没有白色标题栏了，夜间模式整窗一个颜色；能拖动窗口、双击最大化、拖到屏幕边缘贴靠。
- [ ] 窗口标题和任务栏只写“胥宇”。
- [ ] 右下角“?”里能找到原来状态栏那串说明。

**P3**
- [ ] 浮窗不再互相压；半屏（左右分屏比对）时图纸不会被挤没。
- [ ] 工具栏不换行；没打开图纸时只剩能用的按钮（方案、恢复图纸、打开图纸）。
- [ ] 汇总清单里拖一个设备到图上任意位置。

**P4**
- [ ] 换几套风格看看，喜欢哪几套、哪几套要改。
- [ ] 切主题不再“震动”，从点的位置铺开。

**P5**
- [ ] 往存放目录丢一个文件，工作台自动出现；勾选后开始绘图。

**P6**
- [ ] 用一个季度的真实文件走一遍归档（建议先用副本），回退能恢复。

**PI（安装器）**
- [ ] 在一台没装过胥宇的电脑（或新建的 Windows 用户）上双击安装包，不改路径直接点“开始安装”，能装好。
- [ ] 点“更改…”换一个位置也能装好；装完桌面和开始菜单都有“胥宇”。
- [ ] 在已经装了胥宇的电脑上再装一次：显示“沿用原来的位置升级”，装完以前的图纸、方案、设置都在。
- [ ] 卸载：提示数据会保留；卸载后再装回来，数据都在。
- [ ] 安装器每一页字是清楚的（微软雅黑），没有被裁掉的内容；顶部横幅能看清“胥宇”。
- [ ] 软件里“检查并更新”照常能下载并静默安装、重启。
