# 胥宇 CAD 一期（cad-v1）

**目标**：少量 DWG 进来，能做和 PDF 一样的工作（布点、编号、箭头、说明、统计、导出）；导出的 DWG 在别人的 CAD 里还能改；装给十几个同事也能用，出来的结果一样。

> **状态（2026-10-15）：草稿，暂不发。** 用户决定 CAD 放到最后，单独做一个版本。到那时先按下面“CAD 工作区”的方向重写本包，再发给 Codex。
>
> **CAD 工作区（用户嫌现在的 CAD 模块“跟个图片似的”）**：现在的链路是 DWG → ODA 转 DXF → 画成 PDF → 再转成图片铺底（`FloorPlanCanvas` 里 `KonvaImage listening={false}`），所以图层不能开关、不能捕捉、不能点选、尺寸按“纸”算、模型空间被裁成一张纸。方向：保留 ODA 转 DXF 和现有导出写回链路（有保真检查，最扎实），只改“怎么画到屏幕上”——用显卡直接画矢量（候选：`dxf-viewer`，MIT，three.js；先用样本测中文字和大图速度），胥宇对象照旧叠在上面。要有：矢量显示、图层面板、对象捕捉、真实毫米坐标和测距、模型空间漫游加布局标签、点选查看图层和块、搜文字跳转。不做原图编辑。大约 3 到 4 张卡，替换本包 C2 里“显示对得上”那部分；C3 到 C6 基本不变。
> **选图是第一步（用户 2026-10-15）**：大部分图纸是模型空间里摆好几张图，实际只用一张，基本是**平面布置图**；要把其他的去掉，画好后可能单独把这一张导成 PDF。现有的“提取图纸”（`CadExtractDialog` + `extract.py`：手动拖框，框外实体整个删掉、不剪断，另存新 DWG）只能在布点前用、要手动拖框、遇到显示不了的对象就失败。CAD 版的流程：打开 → 自动找出每张图（图框、图名文字）列缩略图，自动选中“平面布置图”，用户点一下确认 → 屏幕只显示这一张（原图不动）→ 设备按 CAD 真实坐标保存，之后换图或调范围不丢点 → 导出 DWG 只含这一张（其他整个删掉，跨界的整个保留不剪断），导出 PDF 只这一张、按图框大小对应纸张、矢量。默认选一张；选多张就是多页。
>
> 还没问到的两件事（已改为让 Codex 统计图纸，见交接文档）：平时在模型空间还是布局里布点、一张图是否常摆多层平面；清单里最想先要哪几样，要不要认出原图已有的摄像机块。另外提议过先做一个能点能拖的原型给用户看手感。

**什么时候开工**：CAD 单独版本开工时（见上）。整个文件夹放进 xuyu 仓库的 `docs/cad-v1/`，开工消息见《给Codex的CAD开工指令.md》。

## 一、已经定下的事

| 事项 | 结论 | 来源 |
|---|---|---|
| 读写 DWG 用什么 | **ODA 免费转换器**（软件里已有这条路），同事电脑不用装 CAD。AutoCAD 2023 适配保留，不扩到别的版本 | 用户确认无 SDK 预算；同事有没有 CAD 不好说 |
| ODA 怎么装 | 第一次打开 DWG 时才装；优先不需要管理员；装完自动接着打开这张图；断网或官网链接失效时，可以“从文件安装”（同事之间传安装包，照样校验） | 本轮决定 |
| ODA 许可 | ⚠ 开发和在用户本机评估可以（9 月已同意）。**给同事日常业务用之前，公司要确认 ODA 的许可**，和代码签名证书一起谈。软件里用团队配置包的一个开关控制（CAD-22） | 旧方案 3.1/3.2 节的许可调查 |
| 导出 DWG 版本 | 和来源一样；2000/2004 的来源导出成 2007 并提示（2007 起中文才是统一编码）；导出时可以手动改 | 本轮决定 |
| 接收端核验 | AutoCAD 2023 自动核验；浩辰 2023、天正 T20 由用户手动看，每次不超过 3 步 | 本机盘点结果 |
| 设备块 | 用户按《块库制作指南》做一个块库 DWG，导入到**绘图方案**里（不另建块库）；团队配置包带着它发给同事 | 旧方案 5.2–5.4 节，用户确认“块并入绘图方案” |
| 图层 | 新导出：`XUYU_DEVICE / XUYU_LABEL / XUYU_ARROW / XUYU_NOTE / XUYU_SUMMARY`；旧的两层（`XUYU_DEVICES / XUYU_ANNOTATIONS`）照样能读 | 旧方案 5.5 节默认提案 |
| 天正图 | 能认出来；带代理图形的照样显示、导出时原样保留；不带的，提示在天正里“图形导出”成 T3 再打开 | 本轮决定 |
| 代码签名证书 | 暂不买（等公司谈）。先做《同事安装说明》，教会“更多信息 → 仍要运行” | 用户 2026-10-15 |
| 字体 | 胥宇自己写进图纸的字用微软雅黑（每台中文 Windows 都有）；图纸原来的 SHX 字体缺了只影响显示：按固定规则替代，并列出缺了哪些；电脑上装了 CAD 的，自动借用它的字体目录（只读） | 本轮决定 |
| 同事规模 | 十几个人，都能上网；有没有管理员权限不确定，所以按“没有管理员”来设计 | 用户 2026-10-15 |

## 三、规则（v4 的《00-硬约束》《07》仍然有效，下面是这一轮另加的）

1. **用 Codex 自己的模型跑，这一轮不切 DeepSeek**：要碰真实图纸。
2. **真实图纸**只读 `D:\my-projects\cad-samples\样本\`。不改、不移、不进仓库、不上传。带文件名的报告只放在 `D:\my-projects\cad-samples\`；仓库里一律用 S01、S02…这样的代号。
3. **测试用图纸**用脚本生成（ezdxf 写 DXF → ODA 转 DWG），放 `tests/fixtures/cad/`，不含任何客户内容。
4. **AutoCAD、浩辰、天正**只在副本上用，不登录、不激活、不改它们的设置。遇到激活或登录窗口就停（之前浩辰就卡在激活窗口）。
5. **门禁**（每张卡结束跑一次；开工前先单独提交一条 docs 提交，作为本卡起点）：
   ```
   node docs/redesign-v4/reference/run-gates.mjs --phase C2 --base <本卡起点> --scope docs/cad-v1/phase-scope.json --trace docs/cad-v1/traceability.json --out docs/cad-v1/reports/gates --wiring-base <C1起点> --e2e <本卡 e2e 文件> --repeat 1
   ```
   编号登记在 `docs/cad-v1/traceability.json`，格式同 v4。`phase-scope.json` 里 `ui` 列出的编号是界面类：要截图，要有 e2e。
6. **卡和卡之间不停**。只有这几种情况才停下来问：要管理员权限、改系统、花钱；许可问题；某类图纸做不到又不愿丢数据（给 2 到 3 个选项）；要改范围外、和 CAD 无关的文件。和本卡主题相关的小范围补充，自己登记，在报告里写一行。
7. **每张卡做完**：报告不超过 15 行，附 summary.md，推到 dev，接着做下一张。需要用户手动核验的，攒到卡结束一次给，每次不超过 3 步，写清楚看什么。
8. **全部做完**：写 `docs/cad-v1/reports/CAD一期最终报告.md`，打一次 Preview 包，然后停。
