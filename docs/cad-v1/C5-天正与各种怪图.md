# C5 天正与各种怪图（CAD-17 至 19）

**为什么**：天正画的墙、门窗、标注是天正自己的对象，没装天正的电脑只能看到“代理对象”。现在胥宇遇到代理对象就拒绝打开。盘点里还有 47 个云盘占位文件、1 个文件头坏掉的文件。

**CAD-17 认出天正，能显示的照样显示**（界面类）
- 打开时识别天正对象（代理对象的类名、所属程序），页面顶部提示“这张图有天正对象 N 个（墙、门窗、标注……）”。
- 代理对象带“代理图形”（天正保存时一般会带，以 C1 体检结果为准）：照着代理图形显示。
- 不带代理图形、显示不出来：提示“在天正里用‘文件布图 → 图形导出’另存为 T3 格式，再用胥宇打开”，并附上一句为什么。
- 导出时天正对象**原样保留**，保真检查必须通过；不炸开、不转换。

**CAD-18 天正接收端**：用户电脑有天正 T20 V9。给用户 3 步手动核验：
1. 用天正 T20 打开胥宇导出的 `S0x-胥宇.dwg`（挑一张天正样本）
2. 看：墙、门窗还是天正对象（双击会弹出天正的编辑框），胥宇的设备和编号也在
3. 改一下胥宇的一个编号，保存；回胥宇打开，能看到改动
- 天正样本只有 `_t3` 版本（已经炸开的）时，在报告里写明，这一项只验 T3。

**CAD-19 各种怪图都给一句人话**，每种配一张 C1 的测试图纸：
- 云盘占位文件（文件还在网盘上）：**先看文件属性，不打开、不触发下载**，提示“这张图还在网盘里，请先下载到本机”。
- 零字节、文件头坏、不是 DWG：提示“文件损坏或不是 DWG”，并显示看到的文件头。
- 很大的图（超过 50 MB 或实体超过 50 万）：显示进度，可以取消；超时说清楚是哪一步慢。
- 图纸带密码：提示“请在 CAD 里去掉密码后再打开”。
- 所有提示都不能是英文堆栈；详细信息放在可展开的“技术详情”里。

**合成测试数据**：天正代理对象能用合成数据做（自己拼代理图形字节）就做；做不出来时用本机天正样本跑验收脚本，结果写进匿名报告，**不要把客户图的任何部分放进仓库**。

**验收**：门禁全绿；12 张样本里的天正图要么正常显示，要么给出 T3 提示；C1 体检复跑后，除了要用户自己处理的（下载、去密码、导出 T3），其余全部能打开。

**报告里写**：样本里天正图的张数、有没有代理图形；给用户的天正手动核验步骤。
