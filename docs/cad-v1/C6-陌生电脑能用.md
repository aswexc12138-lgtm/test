# C6 陌生电脑能用（CAD-20 至 26）

**为什么**：要给十几个同事装。他们有没有管理员权限、有没有 CAD 都不确定；暂时没有代码签名证书。目标：装得上、第一次打开 DWG 不卡住、出问题能一键把信息发回来、大家做出来的结果一样。

**CAD-20 不用管理员装 ODA**
- 先试“只解压不安装”：`msiexec /a` 把官方安装包解到 `%LOCALAPPDATA%\XUYU\components\oda\<版本>\`，不写系统目录，不弹管理员确认。现有的哈希和发布者签名校验一项不少，没通过校验的文件不解压。
- 缺 VC 运行库导致跑不起来：用微软允许的随程序分发方式解决；做不到就停下报告缺什么。
- 解压的路走不通，再退回现在的官方安装窗口，并提示“这台电脑需要管理员同意，请找有管理员权限的人”。
- 用 `runas /trustlevel:0x20000` 以普通用户权限启动胥宇，在本机走完全程：下载 → 校验 → 解压 → 读写验证。**不新建系统账户，不改系统设置。**

**CAD-21 第一次打开 DWG**（界面类）：没装 ODA 时打开 DWG，弹出“打开 DWG 需要一个免费的读取组件（约 xx MB，来自官方）。装好后会自动接着打开这张图”，按钮是“安装并打开 / 取消”。装好后**自动接着打开同一张图**。失败时给原因，并提供“从文件安装…”（同事之间拷来的安装包，照样校验）和“复制诊断包”。

**CAD-22 许可开关**：团队配置包加一项 `cad.odaAllowed`。为 `false` 时，打开 DWG 提示“公司还没开通 DWG 组件，请联系发布人”，不下载。为 `true` 时按 CAD-21 走。没有这一项时保持现状，下载前多显示一句“ODA 是第三方免费工具，公司业务使用以公司和 ODA 的许可约定为准”。

**CAD-23 同事安装说明**：做一页 `同事安装说明.html`，打包时和安装程序放在同一个文件夹。内容：怎么拷（微信、QQ 可能改名或拦 exe，建议压缩后发）；“Windows 已保护你的电脑 → 更多信息 → 仍要运行”；杀毒软件拦了怎么放行；第一次打开 DWG 会装组件；出问题去“配置 → 环境自检 → 复制诊断包”发给发布人。截图能在后台拿到就用真截图，拿不到就画示意图并标“示意”。另外用普通用户权限跑一遍安装程序，确认不用管理员也能装上。

**CAD-24 环境自检**（界面类）：在“配置”里加“环境自检”，每项显示绿、黄、红和一句怎么办：Windows 版本、数据盘剩余空间、WebView2、字体、ODA（有没有、版本、试读写）、AutoCAD 2023（可选）、胥宇版本、团队配置包版本及它要求的最低胥宇版本、更新通道连不连得上。启动时在后台跑，只有影响当前操作的红项才提示。顺便查清现有的自动更新能不能给同事用（从哪儿下、要不要连外网），不能用就在报告里写清楚，这一轮不新做。

**CAD-25 诊断包**（界面类）：一键生成 zip 放到桌面，包括自检结果、版本、最近 7 天日志、CAD 处理日志。**不含**任何图纸、PDF、工程文件、方案包、团队包；路径里的用户名换成 `<用户>`。保存前列出包里有什么，不超过 20 MB。

**CAD-26 字体一致**
- 图纸里的 SHX 字体缺了：中文按固定规则用仿宋显示，**不能出现方块**。
- 电脑上装了 AutoCAD、浩辰、天正的，自动把它们的字体目录加进来（只读）。
- 团队配置包可以带一个共享“字体文件夹”路径。
- 导出时列出这张图用了哪些替代字体。胥宇自己写的字：DWG 里用微软雅黑（每台中文 Windows 都有），PDF 里用胥宇自带的字体，保证每台电脑一样。

**验收**：门禁全绿；普通用户权限下从安装胥宇到打开第一张 DWG 全程录一遍（截图序列）；诊断包内容清单；测试图纸在缺字体时中文正常显示的对比图。
