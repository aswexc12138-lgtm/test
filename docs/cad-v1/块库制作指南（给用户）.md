# 块库制作指南（给你自己做）

**做什么**：一个 DWG 文件，里面放你常用设备的块，比如枪机、球机、半球、NVR、交换机。胥宇导入后，导出的 DWG 里用的就是这些块；别人在 CAD 里双击设备，就能改编号。

**花多久**：一个块大约 5 分钟。先做最常用的 3 到 5 个就够，以后随时可以加。不急，CAD 第 4 张卡开工前做好就行。

**用什么**：AutoCAD 2023（你电脑上有）。新建一张空白图（模板选 `acadiso.dwt`）。

## 六条规矩（照做就不会出问题）

1. **单位用毫米**：输入 `UNITS` 回车，“插入时的缩放单位”选“毫米”。
2. **按打印出来的实际大小画**：比如枪机打印在图纸上是 8 毫米宽，就画 8 宽。
3. **全部画在 0 层；颜色、线型、线宽都选 ByBlock**。这样别人在 CAD 里改图层颜色时，块会跟着变。
4. **只用简单图形**：直线、多段线、圆、圆弧、椭圆、实心填充。不要放图片，不要块里再套块，不要动态块参数。
5. **编号属性**：输入 `ATTDEF` 回车，标记填 `NO`，提示填 `编号`，默认值填 `C01`；文字高度 `2.5`，对正选“正中”。放在你希望编号显示的位置，也放在 0 层。
6. **方向和基点**：摄像机的镜头朝**右**画（胥宇的 0 度就是朝右）；基点放在设备中心。

## 每个块的步骤

1. 按规矩 2 到 4 画好图形。
2. 按规矩 5 加编号属性。
3. 输入 `BLOCK` 回车，在弹出的窗口里：
   - 名称写中文，例如 `枪机`、`球机`、`半球`、`NVR`
   - 基点：点“拾取点”，点设备中心
   - 对象：点“选择对象”，框选图形和 `NO` 属性；下面选“删除”
   - “注释性”不勾；“允许分解”保持勾选
   - 确定
4. 接着做下一个。

## 全部做完

- 另存为 `D:\my-projects\cad-samples\胥宇块库.dwg`，文件类型选 **AutoCAD 2007/LT2007 图形 (*.dwg)**。
- 跟 Codex 说一句“块库做好了，一共 N 个块”就行。

## 一分钟自查

新建一张空图，新建一个红色图层并置为当前层，输入 `INSERT` 插入“枪机”：
- 大小对吗？
- 显示编号 `C01` 吗？双击能改吗？
- 块是红色的吗？是红色说明规矩 3 做对了。

## 常见问题

- **块名重复**：AutoCAD 会问要不要重新定义。只有你本来就想改它时才选“重新定义”。
- **做错了**：输入 `BEDIT`，选那个块，在块编辑器里改完保存。
- **用浩辰或天正做**：也可以，但最后请用 AutoCAD 2023 另存一份 2007 格式。
