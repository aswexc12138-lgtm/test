# C2 和 PDF 一样的工作（CAD-04 至 08）

**为什么**：现在 DWG 遇到动态块、图片、外部参照、三维对象会直接拒绝打开；高亮圈、矩形、椭圆、测量、布设范围也导不出 DWG。用户要的是“DWG 进来，能做的事和 PDF 一样”。

**CAD-04 打得开**（界面类）：按 C1 的失败原因排行，一类一类放宽，每类配 C1 的测试图纸。
- 动态块：按它当前的样子显示；导出时原样保留，不炸开、不改参数。
- 图片：找得到图片文件就显示；找不到就画虚线框，标“缺图片：文件名”。
- 未绑定的外部参照、三维实体、OLE 等显示不了的东西：**不再拒绝打开**，在页面顶部用一条可展开的提示说清楚“有哪几类没显示、各多少个”。导出时这些原图记录原样保留（现有的保真检查必须照样通过）。
- 目标：12 张样本里非天正的全部能打开；重跑 C1 体检，失败率要明显下降。还打不开的，每张都要给用户一句能照着做的话。

**CAD-05 每种对象都能导出**：PDF 流程里能画的，DWG 里都要有。
- 矩形 → 闭合多段线；椭圆 → 椭圆；高亮圈 → 圆；布设范围 → 闭合多段线；长度测量 → 直线加两端短线加文字（不用 CAD 标注对象）；面积测量 → 闭合多段线加文字；统计表和图例 → 文字加设备块，放 `XUYU_SUMMARY`。
- 实在表示不了的（例如半透明填充），导出前在导出窗口里列一张“这些效果只在 PDF 里有”的清单，用户看过再导。**不许悄悄丢掉。**
- 每种对象都要走完：导出 → 另开一次读回核对（现有机制）→ 再导入胥宇。

**CAD-06 显示对得上**：同一张图，把胥宇显示的样子和 AutoCAD 2023 打印出的 PDF 转成图片后逐像素比较。
- 测试图纸的对比图放 `docs/cad-v1/reports/C2/对比/`，Claude 会看。样本的对比图只放 `D:\my-projects\cad-samples\对比\`。
- 重点看：线型（虚线、点划线）、填充图案、线宽、SHX 字体。差距大的写清楚原因，能修的修。

**CAD-07 导回来还能改**：胥宇导出的 DWG 再打开，所有胥宇对象都能选、能改；不重复，编号不变；改完再导出，保真检查照样通过。每种新对象都要测。

**CAD-08 其余流程一样**：DWG 来的工作导出 PDF 时，汇总表、图例、高亮圈、填充都和 PDF 来的一样，底图是矢量的，不能变成图片。资料整理里 DWG 也要有缩略图和预览（用打开过的缓存；没打开过的显示 DWG 图标和版本）。成果库、绩效计数和 PDF 一样。已经做好的标 `already`，并写上代码位置。

**验收**：门禁全绿；体检复跑的前后对比；测试图纸对比图；CAD-04、05 各有 e2e 测试（用测试图纸走一遍打开 → 布点 → 导出）。

**报告里写**：哪些类型放宽了、放宽后保真检查怎么保证；“只在 PDF 里有”的完整清单。
