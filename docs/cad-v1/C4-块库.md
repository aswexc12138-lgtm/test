# C4 块库（CAD-13 至 16）

**为什么**：现在 DWG 里的设备只有内置的 3 种简单符号（枪机、球机、设备）。用户要用自己的块，同事拿到的块也要一模一样。

**CAD-13 从块库 DWG 导入块**（界面类）：在**绘图方案**编辑器里加一节“CAD 符号”，不另建块库。
- 选一个 DWG 或 DXF（用户的 `胥宇块库.dwg`），列出里面所有普通块：名字、预览、尺寸（毫米）、有没有 `NO` 属性。勾选要的，导入。
- 不收的块要说原因：动态块（“请在 CAD 里另存为普通块”）、块里套块、外部参照、带图片的块。
- 导入后存进绘图方案：稳定 ID、内容摘要（哈希）、基点、尺寸、属性。改显示名不改身份。同一个块再导一次不重复；内容变了就是新版本，已导出的成果不受影响。

**CAD-14 设备对应块**（界面类）：在“CAD 符号”里给每种设备素材选一个块；名字相近的先自动建议，用户确认。
- 没配块的设备照样用内置符号，列表里标“未配块”。
- 底图是 DWG 时，画布上的设备显示块的样子（导出什么样，屏幕上就什么样）；底图是 PDF 的工作不变。

**CAD-15 导出用真块**
- 第一次用到时，把块定义复制进图纸，块名用 `XUYU_<显示名>_<摘要前 8 位>`，**绝不覆盖客户图里的同名块**。
- 插入：位置、旋转跟胥宇一致；大小按胥宇里设备框和块外框的比例缩放。
- 编号写进属性 `NO`，标签里就不再重复显示编号；块没有 `NO` 属性时，编号照旧用独立文字。
- 保真检查的“允许新增”名单：从写死的 3 个内置块名，改成“本次登记过摘要的 XUYU_ 块”。
- 导回胥宇：块定义的摘要要和方案里的一致；在 CAD 里被改过的，按现有“块定义已替换”规则处理。

**CAD-16 团队配置包带上块**：导出团队配置包时带上方案里的块（定义和摘要），同事导入后块完全一样（摘要相同）。旧格式的包照样能导入。

**开发时**：用户的块库没做好之前，用脚本生成一个测试块库（`tests/fixtures/cad/块库-测试.dwg`：带 `NO` 属性的枪机、球机，一个动态块，一个套娃块）开发和测试。用户的块库只用来验收。

**验收**：门禁全绿；e2e：导入测试块库 → 配给设备 → DWG 底图布点 → 导出 → AutoCAD 核验脚本（C3）通过，属性 `NO` 能改；团队包导出再导入后摘要一致。

**报告里写**：用户块库导入结果（收了几个、没收的原因）；给用户的 3 步手动核验（在 AutoCAD 里双击一个设备改编号）。
