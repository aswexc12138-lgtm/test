# 胥宇 · 界面改版 v4.1

v4 验收后，用户真机看了方案编辑器那几页，觉得排版松垮、取色器老旧、快捷键太占地方。Claude 把全软件走查了一遍，列出问题，画了设计稿，和用户一起改了四轮，定稿后由 Codex 实现。

## 文件

| 文件 | 给谁 | 内容 |
|---|---|---|
| `给Codex的开工指令.md` | 用户 | 发给 Codex 的那段话（直接复制） |
| `00-规则.md` | Codex（先读） | 顺序、节奏、什么叫做完、数据怎么改、什么时候停、这一轮不做什么 |
| `01-规格.md` | Codex、用户 | 全部编号（V-01 起），每条：现在在哪（文件:行号）、要做到什么、怎么证明 |
| `phase-scope.json` | Codex | 每个阶段的编号、界面类编号、允许改的文件 |
| `界面问题清单.md` | 用户、Codex | 问题从哪来：用户点名的、走查发现的、四轮设计意见；第六节是**原有功能对照表** |
| `设计稿/截图/` | Codex、用户 | 15 张设计稿截图（含左侧联动动画分解图） |
| `设计稿/*.dc.html` | Codex | 设计稿源文件，样式和动画参数可以直接抄（需要设计画布的运行环境才能打开，Codex 看截图和源码即可） |

另外更新了 v4 的两个检查脚本（`docs/redesign-v4/reference/run-gates.mjs`、`trace-check.mjs`）：加了 `--scope`、`--trace`、`--out`、`--wiring-base` 参数，范围文件里可以列界面类编号。v4 的用法不变。

## 阶段

| 阶段 | 做什么 |
|---|---|
| Q1 公共控件 | 数字框（输入 + 滚轮 + −/+）、取色浮层、分段按钮、开关、`?` 提示、紧凑表单行 |
| Q2 配置中心外壳 | 左侧导航顺序、方案总览、方案编辑器顶部一行 + 5 页 |
| Q3 方案编辑器上半 | 基本与编号、分类与汇总说明 |
| Q4 方案编辑器下半 | 设备素材、样式、汇总与导出（含汇总组合） |
| Q5 快捷键页 | 从“通用”里搬出来单独一页，两栏紧凑表格，连续放置快捷键并进来 |
| Q6 绘图 | 左侧资料 / 设备联动和动画、资料默认页、标题栏三段、文件样式和图片大小弹窗换成同一套组件、汇总清单切换组合、两处小问题 |
| Q7 收尾小修 | 完整备份不再带浏览器缓存、删掉仓库根目录的杂文件 |
| 最终 | 全量门禁连跑 3 遍、打 Preview 包、写最终报告和验收清单 |
