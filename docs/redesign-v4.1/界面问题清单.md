## 二、举一反三找到的

**页面结构**
- S1 方案编辑器顶上叠了三层标题：方案库说明条、方案大标题、分页标题，外加每页都一样的一句废话（“编号、分类、尺寸和汇总规则应用于当前绘图方案”）。正文前大约浪费 250 像素。
- S2 有的页面只有一个设置（箭头与图形、导出路径），有的页面塞了两三百行（通用里的自定义快捷键）。
- S3 相关设置散在几处：
  - 样式分在 3 个地方：文字与标注、箭头与图形，还有设备素材页底部的红圈和尺寸。
  - 导出目录有两个：方案里的“导出路径”和资料与企业品牌里的“导出成果根目录”。
  - 分类说明的文字在“业务分类”页，汇总版式却在“分类说明”页，名字也容易搞混。
  - 设备图片尺寸在方案的设备素材页和绘图里的“图片大小”弹窗各有一份。
- S4 配置中心左侧导航把“CAD 支持”放在第一个（CAD 已延后），导航里还塞了一段“使用说明”。
- S5 方案总览里“编辑、新建、设为默认”出现了三处（顶部、第二排、卡片里），还有一个意义不明的“保存”。

**控件和排版**
- C1 很短的值用了整行宽的控件：资料范围、图例排列、默认 DWG 引擎、首次导出结构都是通栏下拉框；起始值、位数、尺寸这类数字框各占四分之一行。
- C2 只有 2 到 4 个选项也用下拉框（横排/竖排、版式、留白），应该改成分段按钮，并配小示意图。
- C3 数字只能手敲，没有加减按钮，也看不到效果。
- C4 每个字段下面都挂一长句说明，应该收进“?”提示，正文最多保留一行。
- C5 快捷键表：输入框和按钮横向位置一行一个样，参差不齐（是布局 bug）。每行都有“清除”“默认”两个按钮。还把“关闭图片大小设置”“撤销素材调整”这种弹窗内部命令也列出来了。
- C6 “全部命令”面板里每一行都有一个“设置快捷键”按钮，执行命令和改快捷键混在一起。
- C7 设备素材一张卡就占满一屏：名称、快捷键、分类、用途、倍率、单位各占一大块，“单独调整”和“移除”是两个半屏宽的大按钮。素材一多就得一直往下翻。
- C8 业务分类每行配一个 3 行高的说明框；排序只有“上移”，没有“下移”或拖动。
- C9 CAD 原生符号那一块整列居中，跟页面其他部分对不齐。

**缺少示意图**
- P1 这些地方改了数字都看不到效果：图片最长边、图片和编号的间距、汇总宽度、分类块留白、图例横排或竖排、红圈外扩和线宽。
- P2 方案页的“文字与标注”没有样例文字（绘图里的“文件样式”弹窗有）。

**绘图界面**
- E1 “图片大小”弹窗：两个基准值共用四个按钮，排成 2×2，左右两列的分组没有道理。应该每个基准值配自己的“− 数值 +”和一个小预览。
- E2 “文件样式”弹窗：6 组样式每组一整行字体下拉加一行预览，太高；应该和方案的样式页用同一个紧凑表格。
- E3 汇总清单底部一直挂着一段使用说明。属性面板里“点位编号”用的是多行文本框。
- E4 底部同时出现两个提示，互相压住。

**其他模块**
- M1 资料整理：三个步骤是三个半屏宽的大块；第一步只有一个通栏下拉框，下面大片空白。“范围”应该做成 3 个带数量的选项卡片。
- M2 绩效：三个步骤做成了三个通栏大按钮，看不出现在在哪一步。

## 三、通用规则（以后所有页面都照这个）

1. 正文最大宽度 1200px。表单一行放“标签 + 控件”，标签在左；控件宽度按内容定：数字约 96px，短下拉 160 到 240px，文本 320px。
2. 每页只有一行标题。说明文字收进“?”，正文最多一行提示。
3. 2 到 4 个选项用分段按钮，开关类用拨动开关，数字用“− 数值 +”，颜色用统一的取色浮层。系统自带的取色器一律不用。
4. 凡是改了能在图上看出变化的参数，旁边都要有实时预览。
5. 同一类设置只放一个地方。绘图里的弹窗和方案页共用同一个组件，只是作用范围不同（本文件或整个方案）。
6. 列表用紧凑行或小卡片，点开再看详情；行内最多一个主要操作，其余收进“⋯”。

## 四、新结构（草案，做设计稿时细化）

**配置中心导航**：通用 → 快捷键（新）→ 绘图方案 → 资料与企业品牌 → 数据与备份 → CAD 支持（放最后）。

**快捷键页**
- 搜索框加分组筛选。
- 每行：命令名，快捷键标签（点一下就开始录新键），“⋯”菜单（清除、恢复默认）。
- 宽屏分两栏显示。
- 默认只列用户会用到的命令，弹窗内部命令放进“显示全部”。
- 各设备的“连续放置”快捷键并到这里的“放置设备”分组。
- “全部命令”面板只显示快捷键标签，底部放一个“管理快捷键”入口。

**方案编辑器**：顶部一行“← 方案库 / 方案名 · 适用范围”、未保存标记、保存按钮，这一行固定不随页面滚动。分 5 页：

1. **基本与编号**：名称和适用范围放一行；编号规则一行，带实时示例（客流1、客流2、监控1）；绩效识别规则收进“高级”，配一个测试框。
2. **分类与汇总说明**：左边是分类表（名称、单行说明、拖动排序、删除），右边是汇总版式（版式、开头模板、留白、宽度）加实时预览。
3. **设备素材**：小卡片网格（缩略图、名称、用途、分类标签）；点开右侧抽屉看详情（分类、用途、默认红圈、倍率、单位、裁边和中心、CAD 符号）。上传、重新裁边、统一中心放在顶部工具条。
4. **样式**：
   - 文字：6 类一张表，列出字体、字号、颜色、字重、对齐、行距，每行带样例。
   - 箭头、重点红圈、设备图片尺寸、图幅自适应，各自配预览。
   - 绘图里的“文件样式”和“图片大小”合并成一个“本文件样式”弹窗，用同一套组件。
5. **汇总与导出**：图例横排或竖排（分段按钮加示意图）、固定汇总设备表、PDF 成果目录、同名处理、保留矢量底图。这里和资料与企业品牌里的“导出成果根目录”是什么关系，要在页面上说清楚，或者合并成一个。

**方案总览**：顶部放“导入、导出、新建”；卡片上放“编辑、设为默认、⋯（删除）”；去掉多余的按钮和那个“保存”。

## 五、设计稿第三轮用户意见（2026-10-16）

| # | 用户意见 | 处理 |
|---|---|---|
| U6 | 数字框的滚轮调整不见了 | 所有数字框：可直接输入、悬停滚轮调、Shift 一次 10 倍，两侧 −/+ 保留 |
| U7 | 取色点“最近使用”就直接切走；色板应是“主色 + 加白”那种 | 点色块只试色、浮层不关，“确定”才生效、“取消”恢复；最近使用只在确定时更新；色板 = 10 主色 + 每列淡 80/60/40%、深 25/50% |
| U8 | 汇总设备做成可选模板（有的要录像机、有的要交换机、有的不要） | 合理。方案里的“固定汇总设备”和本机的“常用设备组合”合并成方案内的“汇总组合”，一个默认；绘图汇总清单顶部可切换；随方案（团队包）分发。旧的本机常用组合要迁进对应方案 |
| U9 | 绘图左侧“资料”（上）和“设备”（下）位置固定；在哪块里点一下，像两个胖子顶肚子：先吸气，再一肚子把对方顶走；是面板自己变形，不是另外画一个圆弧 | 设计稿 Editor（面板自身形变，不叠任何图形）：① 吸气：被点那块的边缘回收约 22px，边缘中间凹进去；② 顶：边缘鼓成整块的圆肚子，压进对方，对方被压出一个凹坑并压扁一下；③ 弹开：对方被顶飞、多缩一截，顶的这块先回弹一点，中间空出一段；④ 顶的这块长进空位，对方回弹停住（约 3/4 对 1/4，小的变淡）。约 0.95 秒，点击本身照常生效。实现提示：边缘凹陷用遮罩挖椭圆、肚子用大圆角，都作用在面板本身 |
| U10 | 当前文件没做完时，点进资料应先显示“页面” | 资料面板默认分页：未完成 → 页面；已完成 → 文件。用户手动切过就记住 |
| U11 | 点位编号“大小写”有什么意义 | 它只改前缀里的英文字母（前缀本来就是自己输入的），建议删掉；已有方案设了大写/小写的，迁移时把前缀文字直接改成对应大小写，导出结果不变 |
| U12 | 没理解“分类独立 / 整张图连续” | 已改：整张图连续 = 全图一个前缀连续编（Cam1、Cam2、Cam3）并显示“前缀”输入框；分类独立 = 每个分类用自己的名字各自从头编（客流1、客流2、监控1） |
| U13 | 左上角是早先做过的一版，为什么没进去 | 规格 G-02 品牌标识：素材「品牌标识.html」（第三版）一直没交给 Codex，所以 v4 各阶段都没排这一项，审计时也没提醒用户，是遗漏。等用户把文件给到，接进标题栏和设计稿 |
| U14 | 顶部几个模块标签放中间，左上角太远 | 设计稿标题栏改为三段：左品牌、中间模块标签、右主题与窗口按钮 |
